# 2026 Agentic AI 智慧代理人企業挑戰賽

參賽者資訊網站，內容依據 NAPAI 計畫內部會議資料整理，並以 GitHub Pages 靜態網站方式部署。

## 本機預覽

```bash
npm install
npm run dev
```

開啟 `http://localhost:3000`。

## GitHub Pages

推送到 `main` 後，`.github/workflows/deploy-pages.yml` 會自動建立並部署靜態網站。

第一次使用時，請在 repository 的 **Settings → Pages → Build and deployment** 將 Source 設為 **GitHub Actions**。
